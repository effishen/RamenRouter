Project background and attribution
----------------------------------
Freerouting: https://github.com/freerouting/freerouting
Freerouting is distributed under GNU GPL version 3.

The historical versions examined during this application's design were:
  Freerouting v2.2.4
  Commit 20f1a72e546b9b23c7ba5127086885cfacbdd4be

  Freerouting v2.1.0
  Commit 89512b982cbe8d00cccc1837823d9cdcd7c24c8a

This browser edition uses a separately implemented JavaScript routing engine.
Its grid-based search and fanout behavior must not be represented as the exact
algorithms or output of either historical Freerouting version.

The interface was adapted from the RamenRouter prototype developed for this
project. The Java prototype is not part of this browser edition's distribution.

No Java runtime, Freerouting JAR, TeaVM-generated engine, native executable,
third-party JavaScript framework or remotely loaded runtime is included.
Browser platform APIs provide file selection, downloads, drawing and workers.
The URLs in this notice are references; the app does not fetch them at runtime.
