ROUTING RULES

    
Routing rules

    
Choose how RamenRouter works, then set any rules for individual nets. Changes take effect when you apply them.

    

    

      

        

          
          
Prepare extra pad escapes around surface-mount components. Short connections needed to reach chosen main routing layers are prepared automatically, even when this option is off.

          
        

        
Refine completed routes and reduce vias.

        
Retry difficult nets and untangle the last few connections. Keep the best checked result.

        
Favor vertical routes on one layer and horizontal routes on the next. Routes may bend or cross directions when needed; this is a preference, not a restriction.

        
Use fixed search-work limits for fairer comparisons between computers. Use the same board and routing rules on both. The time limit still pauses the run; extend it until the job finishes.

        
Advanced rules 1 OPTION
          
Off keeps vias outside SMD pads; short pad traces can reach them when a layer change is needed. On permits vias inside pads without requiring them. Check fabrication suitability before enabling.

        

        
✓ Imported net widths enforced

        

      

    

    

    
Layer checkboxes choose the main routing layers. When a pad is on another layer and vias inside SMD pads are off, the router tries a short, full-width trace to a nearby via outside the pad, then stays on the selected layers. Turn on the separate SMD-via option to permit vias inside pads. This access is automatic for imported and edited layer rules. With all layers selected, routing keeps its usual behavior. Clearances and other routing rules still apply.

    
Prefer shorter routes gives selected nets earlier access to space and favors shorter paths, even if that needs more vias. Completing connections and obeying board rules come first. This does not guarantee the shortest possible path or match trace lengths.

    
Pads and through vias keep their physical layer spans. Selecting a layer here does not change the board’s construction.


    

    
Use * for any number of characters: USB* starts with USB, *CLK ends with CLK, *CLK* contains CLK. Plain text finds any part of a name.

ABOUT RAMENROUTER
Open a file.
Find a route.
RamenRouter is a standalone PCB routing workbench with an independent JavaScript engine. It searches for routes in a browser worker and enforces imported net widths.
This is a routing and inspection tool. Export a Specctra DSN from your PCB editor, route it here, then import the SES result back into your editor.
Everything runs locally.
Open index.html to begin. Your files, routing calculations and exports stay in the browser. No server, Java runtime, installer or internet connection is needed.
Independent GPL-3.0 source and notices are included in this folder. The preview simplifies some board geometry; check exported results in your PCB editor before manufacturing.
